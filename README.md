# Дашборд по уценке и списаниям

Два скрипта. Первый превращает выгрузки iiko в CSV, второй рисует по нему дашборд.

## Что нужно

```bash
pip install pandas matplotlib seaborn openpyxl
```

## Как запустить

```bash
# 1. Выгрузки iiko → один CSV
python prepare_csv.py --vedomost tovarnaya.xlsx \
                      --tovarny tovarny.xlsx \
                      --prodaji20 prodaji20.xlsx \
                      -o dannye.csv

# 2. CSV → дашборд
python dashboard.py dannye.csv --spravochnik Справочник.xlsx -o dashboard.png
```

Получится `dashboard.png` и `dashboard.pdf`.

Посмотреть, как выглядит, не имея выгрузок:

```bash
python dashboard.py --demo
```

## Ключи dashboard.py

| Ключ | Что делает |
|---|---|
| `--shtuki` | Считать в штуках, а не в тенге |
| `--spravochnik ФАЙЛ` | Оставить только витринную продукцию |
| `--filialy ШАБЛОН` | Свой шаблон названия филиала; `--filialy ''` — считать все склады |
| `-o ФАЙЛ` | Куда сохранить |

## Формат CSV

Если делаете CSV сами, нужны эти колонки:

```
дата,филиал,категория,блюдо,событие,количество,сумма
2026-08-01,ТТ1 Атакент,Торты,Наполеон торт,списание,3,22500
```

`событие` — одно из: `продажа`, `скидка_20`, `возврат_по_сроку`, `склад_50`,
`списание`, `возврат_по_качеству`.

Для `скидка_20` в `сумма` пишется **размер скидки**, а не выручка: уценённая
штука — потеря ровно на 20% цены, остальные 80% вы получили.

## Три вещи, о которых стоит знать

**Справочник обязателен, если считаете в штуках.** Без него в потери попадут
моющее средство, упаковка и листья салата — а это больше половины строк.
В деньгах разница 2,1 млн против 2,0 млн, в штуках — 35 468 против 2 688.

**Возврат по сроку виден только вместе с товарным отчётом.** В товарной
ведомости он и уценка на 50% выглядят одинаково — «Расходная накладная».
Различить их можно лишь по колонке «Наименование» товарного отчёта, поэтому
`--tovarny` нужен, иначе возвраты по сроку просто не появятся.

**Неполные недели по краям не рисуются.** Выгрузка редко начинается в
понедельник; неполная неделя всегда ниже полной, и на графике это выглядит
как обвал, которого не было.
